## 需求、范围与验收

用户提供域名证书包并授权配置 HTTPS；明确要求不打断正在运行的服务。配置独立域名反向代理到现有 3000，不重启或重建游戏容器，不关闭原 3000/3001 入口。私钥仅用于服务器 TLS，不加入 Git、日志或文档。

## 调查与决定

- DNS A 记录已指向现有服务器；服务器自带宝塔 Nginx 1.30.4，80 已监听而 443 空闲，系统防火墙已有 80/443 TCP 放行。
- 证书含裸域和 www 的 SAN，有效期至 2027-01-07 06:59:59 UTC；证书与私钥的公钥 SHA-256 完全一致，证书包有三张证书。
- 检查时 3000 有一场真人对局、4 名人类；游戏容器 PID、StartedAt、RestartCount 已留存用于部署前后比较。
- 在现有 Nginx 增加独立 vhost，并先 nginx -t 再平滑 reload。沿用既有 WebSocket map。根路径转发、正确来源头、长连接、素材流式转发均在代理层处理。
- 宝塔全局 proxy.conf 开启共享 proxy_cache；本站显式关闭，避免缓存游戏身份、状态及更新响应。访问日志只记录 URI，不记录查询参数。

## 已完成操作

- 从用户证书包提取链与私钥，安全上传到非网站目录，私钥权限 0600。
- 新增独立站点配置，语法测试成功后通过 Nginx reload 平滑加载；原 IP 的 80 站点和游戏容器保持原设置。
- 新站点 HTTP 返回 308 到 HTTPS；443 提供 TLS 1.2/1.3、HTTP/2，并把根路径和 /ws 转发至 3000。系统防火墙原本已放行所需端口，未调整防火墙、游戏 Docker Compose 或其他站点。
- HTTPS 访问日志启用来源 IP、方法、URI、状态码与 User-Agent；不记录查询参数。私钥位于非 Web 目录，目录 0700、私钥 0600，仅 root 可读。
