# YuriRestia 功能整合

Felix 的 0.2.4 多人版合入 [YuriRestia 的 dev-0.2](https://github.com/YuriRestia/Stronghold-Protocol-EN-translation/tree/dev-0.2)，来源 `ee97ff3c`。原有二十人分组、1–5 倍阶段时长和文件公告保留。

- **时装**：打开「干员调配」，选择干员后切换「时装」；273 款全部可选，改变头像、立绘、小人及适用的召唤物/语音，队友也能看到。支持独立 JSON 导入/导出；自选编队也有入口。数值和战斗规则不变。细节见 [时装说明](OUTFITS.md)。
- **伤害统计**：「交流」旁的图表按钮显示本人干员本回合的伤害，结算显示整局分回合统计；召唤物归主人，同名普通/精锐合并。数据来自本人浏览器模拟，刷新页面会清空该次统计。
- **盟约意向**：确认本局信息时点击核心盟约，告诉同组队友准备走哪个盟约；再次点击取消。同组重复显示冲突，其他固定组可重复选，不被误判为冲突。
- **难度详情**：大厅顶部工具区可以查看难度与领袖、敌人等参数。
- **匹配**：「单人匹配」组成四人公共对局；等待两分钟后可以选 AI 补位，仍受服主 AI 上限约束。私人房间「搜寻队友」只合并相同人数上限、难度及倍率的房间，满所选容量后自动开始。私人房间仍可直接开始。
- **语音和画面**：中/日/英/韩及可用的本土语音，保留原独立语音选择；加入炮击弧线和小人动作裁切修复。初始界面与配音仍为中文。
- **素材管理**：新时装加入现有「预缓存」目录，设置也能打开该管理器；使用现有统一缓存和导入/补齐流程。

来源的分代部署工具随源码保留。本服务器继续使用原 Docker 3000 配置，本次没有启用分代路由，因此更新重启仍可能中断进行中的对局。

实现取舍和实际验证见 [合并记录](development/records/2026-10-12-02-yuri-merge.md)；后续维护以 [D024](development/DECISIONS.md#d024--yurirestia-功能与本分支边界) 为准。
